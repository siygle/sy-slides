Omarchy

DHH 做的 Linux。開機就能用，全程鍵盤操作，AI agent 內建在系統裡。

開場：今天介紹 Omarchy，這是 Rails 作者 DHH 做的 Linux 發行版。官網的定位是「美麗、有趣、agentic」，也就是為 agent 時代設計的可塑型作業系統。今天會聚焦兩件事：鍵盤導向的 Hyprland 平鋪工作流，以及它怎麼把 AI agent 當成系統的一等公民。

Linux 曾經很麻煩。
Omarchy 一次把三件事修好。

官網一開頭就點出痛點：Linux 以前設定繁瑣、很難除錯，一開始就要做很多讓人困惑的選擇。Omarchy 用三招解決：很快的安裝、由 agent 除錯所有問題、以及好到可以直接用的預設值。

Omakase，主廚精選的 Linux。

Omarchy 的 Oma 取自 omakase：工具和細節都替你挑好、調好，你直接開工。但這終究是你的電腦，每一層都能改。

Quickshell桌面建構套件：頂部列、面板、widget
Hyprland平鋪式視窗管理器，所有操作從鍵盤出發
Arch Linux滾動更新的基底，套件永遠是新的
Omarchy 的 Oma 取自日文 omakase，就是主廚精選。它幫你把工具挑好、細節調好。技術上由三層組成：底層是 Arch Linux，視窗管理是 Hyprland，桌面元件用 Quickshell 打造。重點是：預設由他們決定，但每一處你都能改。
35秒

在最快的機器上，從 USB 開機到完整桌面只要 35 秒。大多數電腦不到兩分鐘。

安裝速度是官網特別強調的數字：最快的機器 35 秒，大多數電腦兩分鐘以內。流程只有寫入 ISO 到 USB、回答五個問題，就會交回一套完整桌面。也可以先在 Mac 或 Windows 的虛擬機裡試用。

Hyprland 在 Omarchy 裡有兩種版面。Dwindle 是預設，所有視窗都看得到；Scrolling 讓視窗往右延伸到螢幕外。按 Super+L 就能切換，而且是每個工作區分開記住、重開機也不會跑掉。例如工作區 1 用 dwindle 上網，工作區 2 用 scrolling 寫程式。另外還有視窗群組、scratchpad 等進階功能。

「既然你能 vibe code 出任何想得到的 app，你也應該能 vibe code 你的作業系統。」

David Heinemeier Hansson，Omarchy 作者

這句是 DHH 寫在官網首頁的話，也是下一段的轉折。鍵盤和平鋪讓你操作很快；agent 則讓你能改造整個系統。接下來看 Omarchy 怎麼做到 agent first。

omarchy agent

Agent 不是外掛，是系統的一部分。

Omarchy 給 agent 工具和 skill，讓它幫你理解、修復、改造整個系統。

做 app、外掛、主題

內建的 Omarchy Skill 讓 agent 能改 Hyprland 設定、頂部列，甚至從零做主題。

~/.claude/skills
這是第二個重點：agent first。官網把 agent 當成系統的一等公民，可以分成四個時機看。第一，首次開機就會邀請你選預設 agent。第二，Super+Shift+Ctrl+A 隨時叫出來，或用 omarchy agent prompt 直接交辦任務。第三，系統會監看 systemd-coredump，程式崩潰時跳通知，點一下就交給 agent 診斷。第四，內建的 Omarchy Skill 會連結到 Claude Code、Codex、Pi 等的 skill 目錄，讓 agent 能改設定、做主題。手冊也提醒這個 skill 還在實驗階段，建議先用 plan mode。

老機器也能跑

從最新的 Dell XPS、舊的 Intel Mac，到 2011 年只有 2GB RAM 的 ThinkPad X220。

最後快速帶過其他面向。開發：Neovim 是預設，其他主流編輯器、四種終端機、各種語言環境都整合好了。遊戲：Steam 和 RetroArch 都設定好，連 NVIDIA 驅動也是。需要 Office 的話有 Windows 11 虛擬機，但它沒有 GPU 加速，不適合拿來打遊戲。硬體需求很低，2GB RAM 的老 ThinkPad 都能跑。

社群把 Omarchy 帶到更多機器上。

套件庫pkgs.omarchy.org

Omarchy 自己的 Arch 套件庫，同時建置 x86_64 和 aarch64 版本，ARM 移植因此有地方發佈更新。

edge→rc→stable

Plugin 註冊中心plugins.omarchy.org

數千個社群 plugin，可以先看原始碼再複製指令安裝。例如 Radio Atlas 地球儀電台、AirPods 電量、Omagotchi 桌面寵物、Time Machine 備份。

移植與延伸專案

omarchy-macApple Silicon M1/M2，透過 Asahi Alarm 與 macOS 並存omacom 維護

omarchy-piRaspberry Pi 5 的 SD 卡映像；Pi 4 另有 omarchy-4-pialpha，尚未實機驗證
omarchy-arm裝在現有 Arch Linux ARM：Apple Silicon、Pi 5、VM非官方移植

omarchy-hardwareArduino、ESP32、GPIO widget，以及讓 Claude 操作硬體的 MCP server社群專案
最後補充 Omarchy 的生態系。官方有兩個基礎建設：pkgs.omarchy.org 是自家的 Arch 套件庫，分 edge、rc、stable 三個頻道，而且同時建置 x86_64 和 ARM 版本；plugins.omarchy.org 是社群 plugin 的註冊中心，已經有數千個。在這之上，社群把 Omarchy 帶到更多硬體：omarchy-mac 讓 Apple Silicon 的 M1、M2 跟 macOS 並存，官方團隊頁有專門的 Mac 小組；Dragon 小組在做 Snapdragon 筆電；omarchy-pi 把它移植到 Raspberry Pi 5，目前是 alpha，還沒在實機上驗證；omarchy-arm 是非官方的 ARM 移植。還有受啟發的專案，例如 Pimarchy，以及讓 Claude 透過 MCP 控制 Arduino 和 ESP32 的 omarchy-hardware，剛好呼應 agent first 的主軸。這些專案狀態變化很快，以各自 GitHub 的說明為準。
