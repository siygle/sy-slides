Omarchy

DHH 打造的 Linux，美麗、有趣、agentic。
為 agent 時代而生、可以隨你塑造的作業系統。

開場：今天介紹 Omarchy，這是 Rails 作者 DHH 做的 Linux 發行版。官網的定位是「美麗、有趣、agentic」，也就是為 agent 時代設計的可塑型作業系統。今天會聚焦兩件事：鍵盤導向的 Hyprland 平鋪工作流，以及它怎麼把 AI agent 當成系統的一等公民。

官網一開頭就點出痛點：Linux 以前設定繁瑣、很難除錯，一開始就要做很多讓人困惑的選擇。Omarchy 用三招解決：很快的安裝、由 agent 除錯所有問題、以及好到可以直接用的預設值。

omarchy about

一套 omakase 的 Linux 發行版。

Oma 取自 omakase，意思是「主廚精選」：工具由我們挑、細節由我們調，你直接開工就好。但這終究是你的電腦，每一處都能改。

基底

Arch Linux

滾動更新，套件最新，整個系統完全透明。

視窗管理

Hyprland

平鋪式視窗管理器，所有操作都從鍵盤出發。

桌面套件

Quickshell

桌面建構套件，負責頂部列、面板與各種 widget。

Omarchy 的 Oma 取自日文 omakase，就是主廚精選。它幫你把工具挑好、細節調好。技術上由三層組成：底層是 Arch Linux，視窗管理是 Hyprland，桌面元件用 Quickshell 打造。重點是：預設由他們決定，但每一處你都能改。
35秒

在最快的機器上，從 USB 到完整桌面只要 35 秒；多數電腦不到兩分鐘。寫入 ISO、回答五個問題就完成。

安裝速度是官網特別強調的數字：最快的機器 35 秒，大多數電腦兩分鐘以內。流程只有寫入 ISO 到 USB、回答五個問題，就會交回一套完整桌面。也可以先在 Mac 或 Windows 的虛擬機裡試用。

Super + L

兩種平鋪版面，每個工作區各自記住。

Dwindle · 預設

所有視窗同時可見，必要時就縮小。

適合瀏覽、溝通，以及要一眼看完全部視窗的工作區。

Scrolling

視窗並排延伸，超出螢幕邊緣也沒關係。

適合寫程式：編輯器、終端機、文件一字排開，用捲動切換。

另外還有：Super + G 群組視窗 · Super + S 便籤區（scratchpad） · Super + O 置頂浮動

Hyprland 在 Omarchy 裡有兩種版面。Dwindle 是預設，所有視窗都看得到；Scrolling 讓視窗往右延伸到螢幕外。按 Super+L 就能切換，而且是每個工作區分開記住、重開機也不會跑掉。例如工作區 1 用 dwindle 上網，工作區 2 用 scrolling 寫程式。另外還有視窗群組、scratchpad 等進階功能。

omarchy agent

Agent 不是外掛，是系統的一等公民。

你的 agent 應該在電腦上待得很自在。Omarchy 給它工具和 skill，幫你理解、修復、塑造整個系統。

01 · 首次開機

選擇你的 agent

系統主動邀請你設定預設 agent，登入後就能上工。

omarchy default agent
02 · 一鍵喚起

隨時叫出來

在專屬終端機視窗中啟動預設 agent，也能直接交辦任務。

Super+Shift+Ctrl+A
03 · 崩潰診斷

讀懂 crash dump

程式崩潰時點一下通知，agent 就帶著 diagnose-crash skill 分析原因，並協助回報 bug。

omarchy agent crash <pid>
04 · 塑造系統

做 app、外掛、主題

內建的 Omarchy Skill 讓 agent 能調整 Hyprland 設定、頂部列，甚至從零做出新主題。

~/.claude/skills
這是第二個重點：agent first。官網把 agent 當成系統的一等公民，可以分成四步看。第一，首次開機就會邀請你選預設 agent。第二，Super+Shift+Ctrl+A 隨時叫出來，或用 omarchy agent prompt 直接交辦任務。第三，系統會監看 systemd-coredump，程式崩潰時跳通知，點一下就交給 agent 診斷。第四，內建的 Omarchy Skill 會連結到 Claude Code、Codex、Pi 等的 skill 目錄，讓 agent 能改設定、做主題。手冊也提醒這個 skill 還在實驗階段，建議先用 plan mode。

主題同步

切換系統主題時，Claude Code、Pi、OpenCode 會一起換色。

Omarchy 不幫你選 agent，而是把主流的全部預先接好：Claude Code、Codex、OpenCode、Antigravity、Copilot、Crush、Grok、Pi，還有 OpenRouter 的 ori。它們都是延遲載入的小 stub，第一次執行才會下載。頂部列的 agents 面板會集中追蹤所有訂閱的用量。連換主題時，agent 的終端介面也會一起換色。另外，終端機裡直接打 a，就會執行預設 agent。

為開發者打造，也能玩、也能跑 Windows。

開發

工具都已整合好

預設編輯器是 Neovim，也能裝 VSCode、Cursor、Zed。終端機有 Foot、Alacritty、Ghostty、Kitty 可選。Rails、Laravel、Node.js 從選單一鍵安裝，Mise 管理語言版本。

遊戲與 Windows

工作和娛樂都行

Steam、Proton、RetroArch、Minecraft 都已就緒，包含 NVIDIA 在內的驅動在安裝時搞定。內建 Windows 11 虛擬機，可以跑 Office 和其他 Windows 專用軟體。

硬體

幾乎什麼機器都能跑

從最新的 Dell XPS、讓舊 Intel Mac 重獲新生，到 2011 年只有 2GB RAM 的 ThinkPad X220 都可以。

最後快速帶過其他面向。開發：Neovim 是預設，其他主流編輯器、四種終端機、各種語言環境都整合好了。遊戲：Steam 和 RetroArch 都設定好，連 NVIDIA 驅動也是。需要 Office 的話有 Windows 11 虛擬機，但它沒有 GPU 加速，不適合拿來打遊戲。硬體需求很低，2GB RAM 的老 ThinkPad 都能跑。
